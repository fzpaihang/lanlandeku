## 蓝色水滴残影：v46 已彻底解决

**结论：水滴不是 Android `HandleView`，是 Kivy `TextInput` 自己画的 `_handle_middle`
（`use_handles`，贴图 `shape-drop.png`）。**

修复一行：

```python
# apk/app_ui.py  class RoundInput
from kivy.properties import BooleanProperty
use_handles = BooleanProperty(False)
```

### 为什么之前六版都没修好

v40–v45 全在 Android 侧找原因（`setCursorVisible` / `updateSelection` /
`removeView` / 失焦 / `TYPE_NULL` / AlertDialog）。但水滴是 Kivy 加在
`Window` 上 `canvas='after'` 的一个 widget，由 App 自己的 GL 画布渲染 ——
不是 Window，不是独立图层，杀进程也不消失。

### 决定性判据（下次直接用）

**看它跟不跟着页面滚。** 跟着滚 = 画在 App 画布上 = App/框架画的。
本次坐标 y 从 651 → 529 → 649，随滚动来回动。

其余辅助判据：不进 `dumpsys window`、`SurfaceFlinger --list` 无差异、
杀掉 App 和 IME 都还在、按 HOME 切走再回来完全不变。
