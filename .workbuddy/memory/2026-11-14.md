# apk/app_ui.py  class RoundInput
from kivy.properties import BooleanProperty

### 为什么之前六版都没修好

v40–v45 全在 Android 侧找原因（`setCursorVisible` / `updateSelection` /
`removeView` / 失焦 / `TYPE_NULL` / AlertDialog）。但水滴是 Kivy 加在
`Window` 上 `canvas='after'` 的一个 widget，由 App 自己的 GL 画布渲染 ——
不是 Window，不是独立图层，杀进程也不消失。

## Kivy 单位坑（补充）

`dp()` 返回像素；把「dp 数值」和「像素」直接相减会差一个 density 倍。
`_vcenter(w, row_h)` 就是踩了这个坑：row_h 是 dp 数值、w.height 是像素。
