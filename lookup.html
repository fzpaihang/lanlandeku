查询由 GitHub Actions 执行：提交一个 Issue，机器人会在 30–90 秒内把结果回复出来。 需要 GitHub 账号（GitHub 不接受匿名提交）。

必须选对分区——自动匹配已停用，选错会查不到。输入昵称命中时会自动切到该角色所在区。

UID 是游戏个人信息页里的角色 ID（5–12 位数字），榜外玩家只能用 UID 查。

昵称从已收录的档案里匹配（排行榜 + 历史查询），重名会列出候选让你选。
