这一页的查询功能已经停用。高手榜与经验变化两个页面不受影响，仍在每天自动更新。

为什么停用

  • 浏览器不能直接请求游戏接口：接口不返回跨域头，预检就被浏览器拦下。
  • 所以网页必须有一台后端代为发起请求，而没有稳定且免费的后端。
  • 试过的方案：腾讯云、Vercel 的机房 IP 被游戏风控（握手无响应）；阿里云杭州能通但按量计费；GitHub Actions 能查，但要 登录 GitHub 并等 30–90 秒，体验不成立。

停用只是撤销了「网页发请求」这一层，已收录的昵称数据、榜单数据都完整保留。

现在怎么查

  • 装一个安卓 App，它直接在手机上请求游戏接口，出口是你自己的网络，不受机房风控影响，通常 5–7 秒出结果。
  • 支持输入昵称：本地索引约 8000 人（五区榜单 + 苍松 5 转普查），命中后自动切到对应分区。
  • 查询成功后，昵称会自动补进索引，别人之后也能用昵称搜到这个角色。
  • App 里可直接跳转到本站高手榜，并高亮刚查的那个人。

常见问题

  • 以前查过的记录还在吗？在。查询结果是公开数据，索引仍保留，App 里按昵称就能搜到。
  • iPhone 能用吗？暂时不能。iOS 没有可直接安装的包，需要开发者账号签名（每年 99 美元），目前没做。
  • 网页会恢复吗？如果以后有稳定的免费后端，会重新开放；届时这一页会直接变成查询表单。
