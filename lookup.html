GitHub 驱动 高手榜 ›

查询由 GitHub Actions 执行：提交一个 Issue，机器人会在 30–90 秒内把结果回复出来。 需要 GitHub 账号（GitHub 不接受匿名提交）。

UID 是游戏个人信息页里的角色 ID（5–12 位纯数字），榜外玩家也能查。

流程：填 UID → 点「提交查询」→ 在打开的 GitHub 页面点 Submit new issue → 等 30–90 秒，结果会作为评论出现。

最近提交

每次查询会新建一条公开 Issue（包含 UID 和查询结果），介意的话请不要提交。
数据由游戏接口实时拉取，和排行榜的快照可能有出入。
